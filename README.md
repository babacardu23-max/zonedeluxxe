# Zonedeluxxe — site de la boutique

Site vitrine et catalogue de la boutique Zonedeluxxe (Dakar), conçu par Babacarvalide.

- Site statique (HTML, CSS, JavaScript) hébergé sur Vercel.
- Catalogue, réglages et photos stockés dans Supabase (projet `zonedeluxxe`).
- Lecture publique ; les modifications passent par l'espace gérant (cœur en bas de page) et ne sont acceptées par la base que pour le compte gérant (règles RLS).
